# CSIS 3360 - SPY Stock Market Analysis

## Project Question

Can historical stock-market data help explain and predict short-term SPY market behaviour?

## Dataset

Daily SPY market data from 2015–2025.

Source: Stooq Historical Market Data  
https://stooq.com/db/h/

## Algorithms

The project uses four data analytics approaches:

1. Multiple Linear Regression
2. Association Rules
3. Classification
4. K-Means Clustering

## Team Members

- Nguyên - Regression
- Hưng - Association Rules
- Tuấn - Classification
- Đức - Clustering

## Regression Objective

The regression model predicts SPY's next-day percentage return using historical market indicators including:

- Daily return
- 5-day return
- 20-day return
- Relative price range
- Volume ratio
- 20-day volatility

## Data Split

- Training: 2015–2022
- Validation: 2023
- Testing: 2024–2025

## Disclaimer

This project is for academic analysis only and is not investment advice.
